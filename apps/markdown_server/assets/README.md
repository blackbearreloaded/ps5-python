# PS5 Markdown Server

Drop Markdown notes into `/data/python/docs` and open them from a browser on your LAN.

## Useful pattern

- Keep short setup notes beside your PS5 Python experiments.
- Use fenced code blocks for commands and snippets.
- Set `CPYTHONPS5_DOCS_ROOT` to browse another read-only directory.
